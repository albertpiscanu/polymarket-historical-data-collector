Polymarket Historical Data Collector

A Python tool for collecting, processing, and organizing historical prediction-market price data using REST APIs.

Overview

This project retrieves historical price data for multiple outcomes within a Polymarket event and transforms it into structured tables for further analysis.

It demonstrates practical use of API integration, JSON parsing, data processing, regular expressions, and Excel exports.

Features

Retrieves event and market metadata through the Polymarket API.

Extracts outcome labels and token identifiers.

Collects historical price data for market outcomes.

Processes timestamps and organizes observations into time-series tables.

Exports the results to Excel for further analysis.


Project Purpose

This project was built to explore prediction-market data collection and develop practical experience with APIs, time-series data processing, and data organization.
